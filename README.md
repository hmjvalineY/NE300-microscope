# NE300 複式光學顯微鏡｜互動學習與虛擬實驗

依據本校使用的 **TEKFAR NE300**（`TEKFAR NE300.pdf` 規格）製作的 3D 模型＋互動網頁。

## 開啟方式
- **線上版（GitHub Pages）**：<https://hmjvaliney.github.io/NE300-microscope/>  學生用電腦、平板瀏覽器打開網址即可使用。
- 直接雙擊 **`index.html`**（建議 Chrome 或 Edge）。不需要網路、不需要安裝。
- 整個資料夾可複製到隨身碟、電腦教室或放到學校網站（GitHub Pages、Google Sites 嵌入等）。
- 3D 函式庫已放在 `js/vendor/three.min.js`；若此檔遺失，有網路時會自動改從 CDN 載入。

## 📱 手機使用與安裝成 App（PWA）
- **手機請橫放使用**：左邊 3D 顯微鏡、右邊目鏡視野。左上 ☰ 選章節，右上「📖 說明」開說明與任務、「🎛 操作」開操作面板。直拿時會提示橫放（也可選「仍要直式使用」）。
- **觸控操作（先點選、再操作）**：在 3D 模型上**點一下旋鈕**就會選取它（變藍色，上方出現操作條），之後在 3D 畫面**任何地方滑動**都是在轉它，也可以按住操作條的 ▲▼ 按鈕連續微調；點空白處或 ✕ 取消選取。手指點不準也沒關係，附近的零件也抓得到。教學精靈會自動選好每一步要操作的零件。其他：單指拖曳空白處旋轉視角、雙指縮放；在目鏡視野上**上下拖曳＝細調**。
- **安裝成 App**：
  - Android（Chrome／Edge）：按右上「📲 安裝 App」，或瀏覽器選單「安裝應用程式」。
  - iPhone／iPad：用 **Safari** 開啟 → 分享 → 「加入主畫面」。
  - 電腦（Chrome／Edge）：網址列右側的安裝圖示，或「📲 安裝 App」。
- 安裝後開啟為全螢幕、橫向，**第一次開啟後沒有網路也能使用**（離線快取）。
- **老師更新網站時**：修改檔案後，把 `sw.js` 第一行的 `VERSION`（例如 `ne300-v1` → `ne300-v2`）改一個新值再推上 GitHub，學生端開啟時就會跳出「有新版本，立即更新」。

## 🎓 操作教學精靈（全螢幕）
- 在 3D 區左上角按「🎓 操作教學精靈」，或在「顯微鏡操作步驟」章節按「開始操作教學精靈」。
- 3D 顯微鏡會切換成**全螢幕**，目鏡視野縮成右上角的小畫面，上方有快捷工具列（電源、物鏡、玻片盒、標本夾、目鏡測微器）。
- 小精靈「小微」會用 23 個步驟一步一步引導：從搬運、調暗亮度、開電源、4X、放玻片、夾標本夾、置中、**側面注視上升**、調瞳距、粗調下降、細調、光圈、亮度、倒像，到 10X、40X，最後收鏡。
- **活動標本夾有彈簧**：要「左手撥開並按住 → 右手放入玻片並推到最裡面 → 左手慢慢放開」。玻片沒推到底就放手，夾臂會把玻片夾歪、夾不住（移動載物台時玻片會滑動），精靈會要求重來一次。
- 雙手會「靠近 → 操作 → 離開 → 停一下」循環，讓學生看得到被操作的零件；學生自己在 3D 上操作時，雙手會自動退開。
- 每一步會：轉到適合的視角、讓要操作的零件**閃爍綠光**、出現**3D 雙手**示範動作（握旋鈕轉動、按開關、推目鏡筒、撥光圈環……），並用文字說明原因。
- 學生在 3D 模型上做對了，會自動打勾並在約 1.7 秒後進到下一步；卡住時按「▶ 示範給我看」，雙手會實際操作一次。
- 結束時會顯示用時、看示範的次數、撞片次數。
- 任何時候都可以用 ✕ 或 Esc 離開；不想用精靈時，按「⛶ 全螢幕」也能直接全螢幕自由操作。

## 模擬依據（NE300 規格）
- 目鏡 10X，FN = 20 mm → 視野直徑 = 20 mm ÷ 物鏡倍率
- 物鏡 PLAN 4X/0.10（W.D 28 mm）、10X/0.25（7.4 mm）、40X/0.65（0.65 mm）、100X/1.25 油鏡（0.14 mm），齊焦 45 mm
- 粗調 1 圈 37.7 mm、細調 1 圈 0.2 mm（每格 2 µm）；上限位鎖定
- 聚光鏡 N.A 1.25 附孔徑光圈；3W LED 5700K；載物台行程 74 × 30 mm，右手 XY 同軸
- 景深 ≈ λ/NA² + e/(M·NA)、解析度 ≈ 1.22λ/(NA物鏡+NA聚光鏡)，λ = 0.55 µm（估計值）
- 物鏡工作距離會真的影響操作：高倍時用粗調或在載物台過高時轉換物鏡會「撞片」，蓋玻片破裂

## 教師設定（右上角「設定」）
- **模擬物鏡倍率誤差**（預設開）：每台電腦的物鏡實際倍率略有不同，學生必須真的校正，不能只背「100 µm ÷ 倍率」。
- **換一台顯微鏡**：重新抽倍率誤差與三色絲線順序。
- **顯示本機正確校正值**：教師對答案用。
- 校正值與測量紀錄存在瀏覽器（localStorage），重新整理不會消失。

## 操作小技巧
- 3D 模型：拖曳空白處旋轉、右鍵平移、滾輪縮放；**拖曳或滾動模型上的旋鈕可直接操作**（粗/細調節輪、亮度鈕、XY 旋鈕、光圈環、旋轉盤）；**左右拖曳目鏡筒＝調整雙眼視距**，**左右拖曳右目鏡＝旋轉右目鏡（目鏡測微器跟著轉）**。
- 目鏡視野：滾輪＝細調（Shift＝粗調）；**🔍 放大鏡**以 4 倍重新成像，方便讀刻度；📷 可存圖。
- 鍵盤：方向鍵移動玻片（Shift 慢速）、PgUp/PgDn 粗調、+/− 細調、1～4 換物鏡。
